# SITCON Camp 2026 Prep Course Slides

Marp slide deck for the two-hour prep workshop before the main software engineering and agentic coding course.

## Files

- `slide.md` — Marp slide deck in Traditional Chinese.
- `AGENTS.md` — instructions for future coding agents maintaining this deck.

## Render

Use Marp CLI or the Marp VS Code extension.

Example:

```bash
npx @marp-team/marp-cli slide.md --html --allow-local-files
```

Regenerate the Git local/remote sequence diagram before rendering the deck:

```bash
./render-local-remote.sh
```

## Design intent

This deck is a guided workshop navigation aid, not a keynote. Each slide should help learners know one of the following:

- what concept matters now;
- what to click or type;
- what they should see when the step succeeds;
- which checkpoint they have reached;
- how to ask for help when stuck.
